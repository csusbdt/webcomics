# webcomics

Description

> Interactive web comics implemented as canvas apps

Definition of _canvas app_

> A touch-oriented web app that runs inside a canvas element

Characteristics

- 2D art
- All images are 1920 x 1080, mostly with transparent backgrounds
- Images used for pixel-perfect touch and mouse click detection
- UI sound effects
- Supports music and synchronization with music
- minimal core library easy to understand (canvasapp.js)
